## Added

- An offline desktop dashboard for workouts, nutrition, and body weight.
- An exercise library with custom exercises, reusable routines, set logging, rest timers, and saved workout drafts.
- A workout calendar and history browser for finding and reviewing completed sessions.
- A dated nutrition journal for meals, snacks, and drinks, with reusable food presets and daily calorie and macro totals.
- Weight history, target weight, and analytics for nutrition, body weight, workout activity, and exercise progress.
- CSV and JSON import and export, plus local SQLite backups and restore.

## Changed

- Completed workouts retain the routine plan they started with, so later routine edits preserve the original workout history.
- FitTrack uses its own app icon and stores tracking data locally across launches and reinstalls.
- Distribution includes a per-user Windows x64 installer and standalone executable, a universal macOS disk image, and a Debian amd64 package.
