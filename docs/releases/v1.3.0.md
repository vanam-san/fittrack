## Added

- The exercise library has an alphabetical category filter with exercise counts, including a dedicated cardio and conditioning category.
- All 170 built-in exercises include instructions, equipment, tracking type, and primary and secondary muscle information.

## Changed

- FitTrack uses compact top navigation in narrow windows and keeps the sidebar in wider windows. Dashboard cards, forms, and charts adapt to the available space.
- Date controls stay together and confirmation dialogs scroll in short windows.
