# Code of Conduct

FitTrack welcomes contributors of all backgrounds and experience levels. This code applies to repository discussions, issues, pull requests, and other spaces where someone officially represents the project.

## Expected behavior

Treat others with respect. Discuss ideas and changes on their merits, offer specific and constructive feedback, and respect people’s time, boundaries, and privacy.

Harassment, threats, discriminatory remarks, personal attacks, unwanted sexual attention, and sharing someone’s private information without permission are unacceptable.

## Reporting and enforcement

Use a private contact method listed on the [maintainer’s GitHub profile](https://github.com/vanam-san) if one is available. For abuse on GitHub, use the platform’s [abuse reporting process](https://docs.github.com/en/site-policy/acceptable-use-policies/github-abuse-reporting). Keep sensitive details out of public issues and pull requests.

Give enough context to review the incident, including links or screenshots where appropriate. Maintainers should handle reports discreetly and share identifying information only when necessary to respond. Depending on the severity and frequency of the behavior, maintainers may remove content, issue a warning, or restrict participation temporarily or permanently.

This policy draws on the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
